# attic/

Historical artifacts preserved because they contain information that is NOT
reproducible from git history alone. Nothing in here is built or referenced
by the app.

- `handoff-SPEC.md` — the original project spec from the first session
  (folder preview rework requirements and constraints).
- `cowork-brief.md` — early session brief (pre-dates CONTEXT.md).
- `handoff_bundle.zip` — evidence bundle from the first session: extracted
  decompiled NexusLauncher folder sources + notes used to build the
  folder-preview hooks.
- `_backup_stale-dock-iteration-2026-08-22.patch` — uncommitted dock-columns
  experiment that was backed up before the folder-preview work resumed; the
  dock iteration was never resumed, so this patch is the only record.
- `launcher_grid_export.xml` — William's real home-screen export (4x6,
  includes a widget) captured Aug 2026; served as the format evidence for
  the Import feature and doubles as a layout backup.

Moved here Aug 24, 2026 during the workspace cleanup (v1.2.0 final).
